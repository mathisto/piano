# App Review notes

Page to Hand is a paid, ownership-first piano-practice app. It has no account, sign-in, subscription, in-app purchase, paywall or hidden entitlement. The uploaded build contains the complete app.

## Review without external hardware

1. Open **Songs**.
2. Open **Five-finger warm-up** and choose **Learn**.
3. Keep the on-screen keyboard visible, press **Play**, then tap the highlighted keys. Learn waits for each required note.
4. To see a judged run and its result card, return to the piece, choose **Perform**, and play the short exercise.
5. Open **Songs → Add files** to inspect MIDI, MusicXML and MXL import. Files remain on the device.

An external USB or Bluetooth MIDI keyboard is recommended but not required for review. When connected, the app receives note, velocity and sustain-pedal messages; it does not record microphone audio.

The free browser edition at <https://app.pagetohand.com/> demonstrates the same practice flow. The App Store purchase provides the native iPad app; there is no purchase flow inside the app.

## Content rights

The bundled and downloadable score catalogue contains only public-domain, CC0, CC BY and CC BY-SA material. Credits and source-edition links are visible in the app. The submission dossier is `app-store/rights.md`; the generated per-file licence manifest is `.cache/library/out-fermata/LICENSES.md` and can be attached if App Review asks for it.
