# Row shortcuts

**2 November 2026.** Index rows now carry the action they visibly promise. A tap on the name or empty part of a row starts its existing default action across Today, Read stages and saved Sight runs, Scales, Technique's syllabus and Theory. Songs already opened Learn this way.

Buttons, More menus, remove buttons, links, level selects and their labels remain independent controls. One delegated shell rule enforces that boundary instead of adding page-specific click handlers or boot weight.

The same pass fixed the Read and Scales stage tables below 520px: Typical time hides, leaving useful width for the stage name, mastery and action.
