# Library fingering roadmap

**2 November 2026.** This documentation-only branch records the product contract for generated library fingering before the private engine reaches hand assignment.

- Source fingerings are immutable evidence and are always labelled separately from generated recommendations.
- Ordinary library pieces default to Finger numbers Off. Turning them on starts at Essential; Every note is optional.
- The route choices are Recommended, Source when present, and named purpose-built alternatives. Density and route are remembered per piece.
- The score's base difficulty continues to use the reference player's route. Declared hand reach and route preferences belong in the later `fit()` layer because MIDI cannot identify fingers.
- Catalogue analysis runs offline and ships compact artifacts only. The 223,000-byte boot-JavaScript budget is unchanged.
- Generated-fingering export is available only where the source licence permits adaptations.
- No result ships until deterministic G1 passes its fixed evaluation gate and the patent/publication and freedom-to-operate gate permits disclosure.

No runtime, catalogue, deployment or TestFlight build changed in this branch.
