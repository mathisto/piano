# Grader glissando representation

**5 November 2026.** The private notation adapter now preserves source-authored glissando endpoints instead of dropping or flattening them. Canonical analysis accepts the exact notation but refuses to invent the intervening piano attacks, their timing or their pitch sequence, so the newly acquired source still receives no difficulty grade. Optional cue material remains outside the base performance and malformed unpitched endpoints fail closed.

Exactly one blocked source crosses the strict acquisition boundary. Readiness, every prediction and all development metrics remain unchanged; the holdout remains sealed. Complete verification passes on macOS and independently on `lovelace`. Empty zero-time layout anchors are next, followed by the remaining reusable notation families.

The private mechanism, constants and detailed results remain outside this public repository pending patent/publication and freedom-to-operate decisions. No grade, grader code, app, catalogue, deployment or TestFlight build changes.
