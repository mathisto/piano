# Grader G1 research freeze

**5 November 2026.** The bounded private G1 notation program is complete. Its
final checkpoint improves strict source acquisition but reaches a separate,
explicit timing uncertainty, so readiness, every musical prediction and all
development values remain unchanged.

The fixed release gate still fails. G1 is therefore frozen as private research:
the holdout stays sealed, no grade or grader code ships, and downstream
fingering, fit and library-grade features remain blocked. Resume G1 only for a
separately justified mechanism with a measurable correctness or result-coverage
gain, not another refusal-by-refusal audit.

The complete private seal passes on macOS and independently on `lovelace`; its
disposable verification tree was removed. The mechanism, constants and detailed
results remain outside this public repository pending patent/publication and
freedom-to-operate decisions.

Primary roadmap work now moves to launch readiness: import and recovery, folder
sync, touch and accessibility, support and purchase flow, and real-user iPad
validation. No app, catalogue, deployment or TestFlight build changed.
